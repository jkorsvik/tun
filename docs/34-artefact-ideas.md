# 34. Artefact ideas: what to build next, and what would make it worth building

**Reader:** contributor — you can change the toolkit, and you want to know which shapes are missing before you add a twenty-first builder.

Twenty shapes answer twenty questions, and the gaps are no longer obvious from reading the
code: `docs/33` lists what exists, which is a different question from what is missing. This page
is the other half. Every candidate below is a question somebody has actually asked in a meeting,
with the trap that makes the shape harder than it looks, and an honest note on whether the data
to build it is in reach.

Six candidates have already left this list: the box plot was built as
[48](../examples/48-boxplot/), the Gantt as [49](../examples/49-gantt/), the calendar as
[50](../examples/50-calendar/), the bullet as [51](../examples/51-bullet/), the Pareto as
[52](../examples/52-pareto/) and the Sankey as [53](../examples/53-sankey/), each in the same
week it was written down, which is the cheapest possible answer to a gap. None of the rest is a
commitment; the last section says what it takes to move one from here into `tools/`.

## Ideas that are not a new shape

The toolkit is a format, not a chart library, and some of the largest gaps are not drawings:

- **A manifest beside the build.** `tun.json` next to the artefact, naming its kind, its source,
  its row count and its build time, so a folder index is generated by reading a file rather than
  parsing its own HTML.
- **"What changed since the last build."** A monthly refresh gets re-read before it is shared. A
  diff of two builds of the same artefact, in the same words a reader would use ("twelve numbers
  moved, two by more than 10%"), is the check a person does by hand today.
- **A preview card.** A shared link shows whatever the host guesses. A generated 1200x630 image
  with the title, the one number and the provenance line makes a link look like the report it is.
  The public site already has one; the artefacts do not.
- **Colour-vision simulation inside `verify_a11y`.** The gate measures contrast ratios; it does
  not simulate deuteranopia, and the categorical series is exactly where that matters. A filter
  applied to the screenshot is measurable and would catch a two-colour series that reads as one.
- **A second language proven by a reader, not by a hash.** The i18n suite pins the English
  build; nothing checks that an English page's *sentences* read as English rather than as
  translated Norwegian. That is a judgement, and a lens worth writing down.
- **A pack, not a file.** Six one-pagers with a contents page and one provenance block, printed
  as one document. The one-pager (37) is measured; the pack is not built.

## What it takes to move one from here into `tools/`

Each of the twenty shapes cost the same five things, and a candidate that cannot pay for all
five is not ready:

1. **A refusal list.** What the builder will not draw, in sentences that name the fix. Every
   shape here has one, and the ones that matter are the cases where the picture would be *true
   and misleading*.
2. **A suite that re-derives the drawing** from the source rows, not from the builder. A check
   that reads the builder's own arithmetic proves the arithmetic is self-consistent, which is not
   the question.
3. **At least three mutation controls**, each breaking one named check, so the suite is shown to
   be capable of failing.
4. **A measurement in a browser** for whatever only a browser can see: label collisions, text
   under the floor, a colour that fails in dark. Three of the twenty found their worst defect
   this way, and all three had passed every assertion.
5. **Registration**: two languages, the colour seam, a route from `tun-new`, the dark gate, the
   example-data allowlist, a README with the verify commands, and a row in `docs/33`.

A shape that answers a question nobody has asked yet is not ready, whatever its size. The map is
the largest gap on this page and the one that needs the most care: geometry is data, and inventing
it would be the first time this repository put a number on a page that nobody could trace.
