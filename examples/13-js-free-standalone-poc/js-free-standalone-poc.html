Om denne siden

Bevis-av-konsept for issue #30. Meny, sideskift og dette panelet bruker ingen JavaScript i det hele tatt — prøv å skru av JavaScript i nettleseren og se at ingenting endrer seg her.

Rører ikke examples/10-consolidated-standalone-demo/, som fortsatt er JavaScript-drevet slik den alltid har vært.

Begrenset forhåndsvisning– bør åpnes i nettleser.

Grafer: tre ulike svar på "hva om JavaScript ikke kjører"

1. Stolpediagram — god HTML/CSS-erstatning finnes

CSS-versjonen under er alltid i DOM-en og alltid korrekt. Kjører JavaScript, tegnes en finere canvas-versjon over den — men CSS-versjonen er aldri gjettet bort før JS beviselig har lyktes.

2. Spredningsdiagram med trendlinje — ingen fullgod HTML/CSS-erstatning finnes

Å plassere vilkårlige punkt og beregne en regresjonslinje er ikke noe CSS kan gjøre uten JavaScript. Her forsøker vi ikke et falskt/misvisende forsøk — vi sier rett ut at det kreves JavaScript.

Begrenset forhåndsvisning– bør åpnes i nettleser. Krever JavaScript som ikke er støttet i denne visningen.

3. Fullskjerm — ingen erstatning, skjules i stedet

Fullskjerm-knappen øverst til høyre finnes kun i DOM-en som hidden. Uten JavaScript vises den aldri. Med JavaScript vises den bare hvis requestFullscreen() faktisk lykkes når den prøves — ikke bare fordi funksjonen finnes (se examples/07-topbar-pattern-demo/ for hvorfor det skillet finnes).

Javascript-løs standalone HTML

Denne siden beviser mønsteret fra issue #30: meny, sideskift, info-panel og tema-bryter over krever ingen JavaScript i det hele tatt. De er bygget med <input type="checkbox"> + :checked på avkrysningsbokser og radioknapper — ikke som en reserveløsning for når JavaScript feiler, men som eneste implementasjon.

Gå til grafer-siden for de tre resterende svarene: JS-forbedret-med-CSS-fallback, JS-eneste-med-tydelig-melding, og skjult-uten-erstatning.
