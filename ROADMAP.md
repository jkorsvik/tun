# Roadmap

**This is Tunkallen's project and the direction is his.** What follows is the state of the
plumbing, the work that is ready to do, and the questions that block the rest. If his
priorities differ from this list, **this list is wrong.** Rewrite it.

Rewritten 2026-10-16 from a measured audit of the repository, its issues and tun.community.
Every item names its evidence, so it can be checked instead of trusted.

---

## Where it stands

Shipped and in use:

- Twenty-six artefact kinds from stdlib-only builders (`tools/build_*.py`), all of them with
  `--lang nb|en`: bundled and paired dashboards, the dense cube, the register, the
  comparison, the timeline, the Gantt, the calendar, the distribution, the survey board, the
  folder index, the printable one-pager, the scorecard, the bullet, the Pareto, the Sankey,
  the waterfall bridge, the composition, the funnel, the heatmap, the cohort grid, the small
  multiples, the rank change, the scatter, the box plot, process diagrams and portable slide
  decks. Twenty-four of the twenty-six templates behind them inline the shared colour seam and
  follow the reader's system dark setting; the two that do not are named, with their reasons,
  in `tests/test_dark_scheme_gate.py`.
- Nine `tun-*` skills, installable into RAIWork, Claude Code and every Agent Skills tool
  (`python3 setup.py --tool raiwork|agents|claude`).
- Verification in a real browser, in Chromium, Firefox and WebKit (`--engines`), run on every
  public pull request.
- Hosts measured against the live tenant: SharePoint, OneDrive, Teams, e-mail, USB, cloud
  folders and Atlassian Artifacts (`docs/01`, `docs/26`, `docs/29`).
- Public since 2026-10-11 (AGPL-3.0 with the artefact exception), the Marketplace plugins
  `tun` and `tun-eksempel`, and the page at tun.community.

Measured on 2026-10-16:

## Explicit non-goals

Recorded so they do not creep back in:

- **A filter that pretends to be a security control.** The folder a file sits in is the
  boundary. Different audiences get different data files, split before writing.
- **Defeating `Content-Disposition: attachment`.** It is an XSS control in a tenant's
  document store. We route around it; we do not break it.
- **A build toolchain on the Tier 1 path.** Nothing to install, no framework, no Node.
- **Becoming a BI platform.** No semantic layer, no lineage graph, no scheduler. If a need
  really requires those, the answer is Power BI, and we say so quickly.
